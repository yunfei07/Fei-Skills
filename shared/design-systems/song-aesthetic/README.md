# Song Aesthetic Design System

[定位] 这是 Fei-Skills 的共享数字视觉系统。它把宋式美学转译为可执行的界面、图表、空间和视频规则，而不是把历史符号当作装饰模板。

## 核心原则

1. **留白先于装饰**：用空白建立层级、呼吸和节奏，不用密集卡片填满画面。
2. **低饱和、低对比、清晰层级**：以纸白、墨色、宋淡青、灰绿为主；强调色只服务于信息优先级。
3. **细线代替厚重容器**：优先使用细分隔线、基线、坐标轴和开放布局，避免厚边框、重阴影、玻璃拟态。
4. **书卷式阅读节奏**：标题、正文、图解和注释沿连续阅读流展开，避免典型 SaaS dashboard 的卡片拼贴。
5. **运动克制**：优先淡入、线条生长、缓移、相机微推；禁止弹跳、旋转炫技、强缩放和无意义粒子。
6. **信息真实性优先**：审美不得弱化因果、比例、标签、来源或事实边界。
7. **数字化而非仿古**：默认禁止卷轴边框、印章、仿毛笔字、水墨飞溅、宫灯等伪历史装饰，除非内容本身需要。

## 色彩

机器可读值见 `tokens.json`。主色族：

- paper / paper-deep：米白与雾白纸色
- ink / ink-soft：主墨与次级墨
- song-green：低饱和灰绿
- song-cyan：宋淡青
- mist：浅雾灰
- line：细分隔线

## 排版

- 中文标题：优先 Songti SC / STSong / Noto Serif CJK SC 等宋体或衬线回退。
- 英文标题：优先 Georgia / Source Serif / system serif。
- 正文：中文可继续使用宋体或中性系统字体，英文使用高可读 serif/sans 混排。
- 标题不采用 SaaS 式超粗、超紧字距；优先中等字重、较宽行距和较短行长。

## 图表

- 默认无外框，极少网格线。
- 轴线与参考线使用 `line`，数据主序列使用 `song-green` 或 `ink`。
- 直接标注优先于图例；只在必要时使用第二强调色。
- 动画必须表达数据变化，不得只为“动起来”。

## Three.js / WebGL

- 使用哑光、低高光材质。
- 背景保持 paper / mist 范围，不使用黑色宇宙、霓虹或赛博发光。
- 相机运动慢且单一；空间深度只在确实帮助理解时使用。
- 任何 3D 场景必须有 2D / 文本 fallback。

## Video

- 默认 24 或 30 fps。
- 场景间转场以 dissolve、paper fade、line wipe、slow push 为主。
- 每镜头只保留一个主视觉动作。
- 字幕、标签和图表保持静态可读时长；不要让文字持续漂移。
- 声音设计以轻环境音、纸张感、极弱提示音为可选层，不用强烈 trailer hit。

## 适用范围

此设计系统可由 Web、Video、Image、Storyboard、Data Visualization Skill 共同引用。各 Skill 可以增加媒介特定规则，但不得修改核心信息层级和审美边界。
