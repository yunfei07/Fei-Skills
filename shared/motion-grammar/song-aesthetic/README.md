# Song Aesthetic Motion Grammar

Song motion is restrained but not static. Motion must reveal order, causality, relation or emphasis.

- `ink-line-grow`: a hairline grows along the direction of explanation. Use for causal links and attention relations.
- `layered-emergence`: semantic layers appear one by one with small vertical displacement and opacity change.
- `focus-reveal`: surrounding context remains quiet while the focal object gains contrast or line weight.
- `quiet-parallel`: parallel lanes emerge with slight staggering, then settle simultaneously.
- `paper-dissolve`: low-contrast scene transition; never use as the only explanatory motion.

Timing defaults: 420–900ms for local reveals. Avoid bounce, spin, elastic overshoot, constant ambient motion and dramatic scale changes. A stable reading plateau must occupy at least half of a scene duration.
