# Fei Visual Explanation Grammar

Visual Grammar sits between knowledge structure and renderers. It answers: **what perceptual action makes this mechanism easiest to understand?** It is not a chart gallery and not an aesthetic skin.

## Director rule

Choose a grammar by the explanatory verb, not by available technology. Every scene must have one dominant explanatory verb and one focal relationship. If a static view is clearer, do not add motion or 3D.

## v1 grammar

- `projection-split` — show one representation transformed into several learned projections, then recombined. Use for Q/K/V-like branching.
- `attention-map` — show one focus item assigning different strengths to peers. Line strength or opacity carries weight; exact values remain directly readable.
- `parallel-heads` — show several parallel learned views from a shared input, then concatenate/project. Do not assign fixed human meanings to heads unless evidence supports it.
- `layer-stack` — show a repeated block with internal sublayers and residual flow. Use when repetition and hierarchy are the claim.
- `process-flow` — ordered transformation when branching, weighting or hierarchy are not the main point.
- `comparison` — two explicitly comparable states or architectures.
- `focus-reveal` — editorial emphasis when one local detail must be revealed before the whole.

## Quality bar

A director-grade scene should survive as a still image, make the primary relationship readable within a few seconds, use motion only to stage causality or order, label metaphors as illustrative, and preserve a text fallback.
