# 志怪 / zhiguai

[可见记录] 最初测试为游方道士、雾中竹林、废弃古寺和漂浮纸灯。

[本版实现] 以日常材质中的单一异常制造悬念。运行时修饰词来自 `assets/profiles.json`。

- 先建立正常空间，再给一个异象：无风自移的灯、不同步倒影或无脚印来客。
- 使用克制冷暖对比、纸灯实光、薄雾、局部轮廓光，保留异常可读性。
- 保留古代志怪叙事的含混空间；不默认套用西方恶魔或血腥符号。
- 让谨慎姿态、目光和异象位置对应，使单帧可理解。
- 不把灵异叙事、象征、仪式或虚构实体说成现实存在或有效的事实。

例：读取 `assets/examples/zhiguai-storyboard.json`，写进入竹林、发现浮灯、寺门前迟疑三镜提示词。
