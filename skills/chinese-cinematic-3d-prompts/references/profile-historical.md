# 历史人物 / historical

[本版实现] 使用共享动画底座，区分史料与造型设计。运行时修饰词来自 `assets/profiles.json`。

| 等级 | 工作方式 |
|---|---|
| stylized | 默认；造型标创作提案，不宣称完全准确 |
| inspired | 保留已核查背景，记录来源和艺术加工 |
| strict | 先核查关键视觉事实；证据不足不冒充完成 |

- 收集姓名、时期、事件，以及需要还原的服饰、器具、建筑。
- 用真正读过的可追溯资料支持事实；有检索能力时优先博物馆、文献、学术来源。记录“具体主张 + 来源 + 核查状态”，不用孤立 URL 代替证据。
- 争议事实说明不确定性；不知道就说不知道。不虚构画像、容貌或引用。
- 自拟脸型、体态、表情和镜头叙事标创作提案。
- 脚本只要求 strict 有 source_notes，不核实来源，不能用运行成功作考据通过。
- 避免现代道具、时代混搭、无来源的精确复原措辞；神化人物需标明幻想加工。

例：为指定人物的书斋场景写提示词；未指定考据时采用 stylized 并说明创作边界。
