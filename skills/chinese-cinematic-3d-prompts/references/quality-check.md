# 交付检查

1. **输入**：四个核心字段具体；Profile 合适；默认公开；用户禁用项保留；冲突已解决。
2. **角色**：单幅无锁不能宣称一致；分镜有视觉锚点；每镜锁句一致；动作不覆盖固定外貌。
3. **风格**：底座逐镜重复；Profile 只叠加叙事；黏土与电影灯光共存，无现代器物或塑料漂移。
4. **镜头**：一个主要动作；目光与焦点对应；分镜推进明确；时长只是规划，不称视频成品。
5. **史实**：strict 事实有读过的来源；不足标待核实；创作和史实分开；不将象征变成现实结论。
6. **输出**：英文提示词、负向约束、参数、角色锁、默认项、证据说明、真实检查状态齐全。
7. **工具**：实际运行才说已运行；只描述结构检查；视觉一致性与负向支持需目标工具中检验。

脚本不检测自由文本语义矛盾。模型负责第 3–5 项；修复可逆错误后再交付。


## 分镜制作附加检查

- 同一 scene_id 的布局、建筑与道具不漂移；局部取景不能与锁冲突。换地点显式切换 ID。
- 参考来源真实；登记、可访问、已查看、已传入出图工具、已用于结果是不同状态，不混淆。resource_id 不等于图像字节。
- camera_motion 的类型、说明与起止构图一致；静态提示词只描述一帧。
- sound 为规划；台词若自拟则标创作提案；不得说已经配音。逐镜覆盖保留所需环境声。
- 时间轴完整后核对总时长；转场在源镜头时长内；末镜没有无目标转场。
- HTML 图片数与实际提供一致，待出图明确标注；图像是否吻合镜头、人物与空间仍需视觉审阅。打开 HTML 查看，再检查打印样式；长文本、中文和竖幅不溢出。
