# Example: Stageshow 入门指南

## Source
`benjitaylor/skills` → Stageshow.

## Audience
People who are new to Stageshow and want to understand whether they can use it and how to start. Avoid audience labels such as “小白”.

## Goal
After one 9:16 infographic, the viewer should know:
1. what Stageshow is;
2. what it can make;
3. what is required before starting;
4. how to install it;
5. how to ask a coding agent to use it;
6. what the internal workflow roughly does;
7. what outputs to expect;
8. where to go next.

## Information architecture

### Hero
`Stageshow 入门指南`
Value line: `让 AI Coding Agent 帮你做产品级 UI 展示图与交互 Demo`
Hero illustration: laptop + phone + product UI + one visible cursor/action/result relationship.

### What it can do
- 产品静态图
- Hero Demo
- Cursor Demo
- Bento Grid

### What it is
`给 Coding Agent 的产品视觉与动效 Skill + React Kit`
Supporting idea: design composition + motion choreography + film/check/refine.

### Before starting
Show prerequisites as three recognizable objects: Node.js, Coding Agent with Agent Skills support, React project or agent-created project.

### Installation
Make the command the dominant exact string:
`npx skills add benjitaylor/skills --skill stageshow`

### First-use formula
`目标 + 产品/内容 + 动作/流程 + 使用场景/尺寸`

Example request should be labeled as an example, not an official command.

### Internal workflow
`理解需求 → 找 Gold Example → React Kit 搭界面 → 编排 3–5 个 beats → Film/Rehearse → 与 Gold 对比 → 修正优化`

### Outputs
- 产品静态展示图
- Hero / Feature Card
- Cursor 交互 Demo
- 手机 App Demo
- Bento Grid
- 可继续修改的 React Component

### FAQ
Use neutral heading `常见问题（FAQ）`.
Answer whether coding knowledge is required without claiming it is a no-code tool.

### Advanced learning
Gold Examples / Framing / Craft / Motion / Playground / Film & Rehearse.

## Visual profile
9:16, warm off-white paper, black ink, pale celadon and sage, limited warm-yellow highlights, hand-drawn watercolor technical illustration, generous whitespace, subtle bamboo and mist-mountain atmosphere.

## QA notes
- Do not use “小白”.
- Installation command must remain exact.
- Do not invent performance statistics.
