# Profile: process-guide

Use for workflows, checklists, operational SOPs, tutorials and decision sequences.

## Information order
start state -> required inputs -> ordered actions -> checks -> result -> next step

## Composition
Use a single visual path with numbered or causally connected steps. Branch only where a real decision exists. Do not turn every step into an equal card.

## Copy rule
Each step starts with an action verb. Keep commands and field names exact. Distinguish required steps from optional tips.
