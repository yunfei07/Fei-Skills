# Profile: beginner-onboarding

Use for first-time users, setup guides, product onboarding, Skill introductions and “how to start” explainers.

## Audience contract
Assume low prior knowledge without labeling the audience as inferior or naive. Prefer 入门指南, 快速开始, 第一次使用, 基础教程.

## Information order
1. What it is
2. What it can do
3. What is required
4. Install / start
5. First-use formula
6. What happens next
7. Outputs
8. FAQ / next steps

## Composition
A large hero illustration establishes the product/tool. The center of the poster is an action path. FAQ and advanced learning live at the bottom.

## Copy rule
Use concrete verbs and exact commands. Explain jargon at first use. Do not over-explain implementation internals before the first-use path is clear.

## Default
9:16, song-handdrawn, mobile-first.
