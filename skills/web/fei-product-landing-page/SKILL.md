# fei-product-landing-page

Use this Skill to create a product marketing site or landing page from real product/brand evidence.

## Inputs

Required: `product_source`, `goal`. Optional: `audience`, `profile`, `sections`, `brand_assets`, `framework`.

Profiles: `editorial`, `minimal`, `cinematic`, `technical`, `luxury`, `playful`.

## Workflow

1. Extract supported product facts, positioning and CTA.
2. Build message hierarchy before choosing layout.
3. Define design tokens: type scale, spacing, radii, elevation, motion and media treatment.
4. Build page architecture from product needs rather than a fixed template.
5. Use authentic UI/screenshots when product UI is shown.
6. Add motion only where it clarifies hierarchy, state or product behavior.
7. Implement responsive semantics, keyboard access, reduced motion, SEO metadata and performance budget.
8. QA all claims, links, form states and mobile breakpoints.

## Outputs

`product-facts`, `message-map`, `page-architecture`, `design-tokens`, `component-map`, optional project source/build.

## Hard rules

Never fabricate customers, logos, metrics, security claims or integrations. Avoid generic template filler when evidence is missing; mark missing content explicitly.
