# fei-product-launch-video

Use this Skill for product launch films, feature announcements, UI demos and short brand/product explainers.

## Inputs

Required: `product_source` (URL, supplied materials, or local project) and `goal`. Optional: `duration`, `audience`, `profile`, `aspect_ratio`, `cta`.

Profiles: `keynote`, `editorial`, `cinematic`, `technical`, `minimal`.

## Workflow

1. Inspect product source and extract only supported claims.
2. Identify launch thesis: problem, differentiated capability, proof, CTA.
3. Select real UI states/screens needed as evidence.
4. Write a beat sheet and narration/copy.
5. Build storyboard with kinetic type, UI crops, push-ins, transitions and sound cues.
6. Establish brand tokens and safe typography rules.
7. Produce a scene/timeline implementation plan, preferring programmable UI animation over fabricated product footage.
8. QA every on-screen claim against source material.

## Outputs

`product-facts`, `launch-thesis`, `script`, `shot-list`, `storyboard`, `asset-map`, `timeline`, optional project source and rendered video.

## Hard rules

Never invent testimonials, metrics, integrations or product states. If UI evidence is unavailable, mark the shot as conceptual rather than presenting it as actual product UI.
